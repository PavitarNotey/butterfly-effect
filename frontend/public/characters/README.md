# Football player asset

`football-player.glb` is a single-primitive adaptation of the unchanged
`voss/player.glb`, using Quaternius Universal Base Characters Standard and
Universal Animation Library Standard. The exact acquired archives dedicate their
contents under CC0 1.0. No new asset pack was used for the full-team version.

Original notices: `voss/base-license.txt` and `voss/animation-license.txt`.
Source URLs, archive hashes, modifications and reproduction instructions:
`docs/CHARACTER_ANIMATION.md` in the Butterfly Effect source repository.
